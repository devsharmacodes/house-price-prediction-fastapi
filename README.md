🏠 House Price Prediction using Linear Regression

📌 Project Overview

This project is an end-to-end Machine Learning application that predicts house prices based on input features using Linear Regression.
The model is trained using Scikit-learn and deployed as an API using FastAPI so that users can get real-time predictions.
